# Лабораторная работа №1: Последовательное умножение матриц

## Описание программы

Программа на C++ для умножения двух квадратных матриц.

- **Входные данные:** два текстовых файла, содержащих матрицы.  
  Формат: первая строка — размер N, затем N×N чисел.
- **Выходные данные:** текстовый файл с матрицей-результатом.
- **Верификация:** автоматическое сравнение с результатом библиотеки NumPy (Python).

## Структура проекта

| Файл | Назначение |
|------|------------|
| `src/main.cpp` | Основной код программы (умножение матриц) |
| `scripts/gen_matrix.py` | Генерация случайных тестовых матриц |
| `scripts/verify.py` | Верификация через NumPy |
| `scripts/test_verification.bat` | Автоматические тесты корректности |
| `scripts/benchmark.bat` | Тестирование производительности |
| `build.bat` | Компиляция программы |
| `data/` | Папка для входных и выходных файлов |

Анализ результатов
Временна́я сложность
Время выполнения растёт пропорционально O(N³). При увеличении N в 2 раза время увеличивается примерно в 8–9 раз (теоретически в 8 раз).
Пример: N=200 → N=400: 0.016 с → 0.153 с (≈9,6×).

Производительность (GFLOPS)
С ростом размера матрицы производительность падает:

1.00 GFLOPS при N=200

0.21 GFLOPS при N=2000
Причины: кэш-промахи и ограничение пропускной способности памяти.

Объём задачи

Для N=2000: 8×10⁶ элементов ≈ 64 МБ памяти

Количество операций: 2 × N³ = 1.6×10¹⁰ операций с плавающей точкой

Вывод
Программа успешно решает задачу умножения квадратных матриц.
Временная сложность соответствует теоретической O(N³).
Результаты верифицированы с помощью NumPy (погрешность в пределах 10⁻¹¹).
Производительность снижается при больших N из-за неоптимального использования кэш-памяти, что характерно для последовательного алгоритма.
