# Умножение матриц с распараллеливанием (MPI) на суперкомпьютере "Сергей Королёв"

## Описание

Программа на C++ для перемножения квадратных матриц с использованием технологии MPI (Message Passing Interface). Автоматическая верификация результатов через Python (NumPy).

## Структура проекта

| Файл | Назначение |
|------|------------|
| src/main_mpi.cpp | Исходный код C++ (умножение матриц + MPI) |
| scripts/verify.py | Проверка результата через Python/NumPy |
| scripts/gen_matrix.py | Генерация тестовых матриц |
| scripts/benchmark_mpi.sh | Серия экспериментов производительности |
| scripts/plot_mpi.py | Построение графиков |
| build.sh | Компиляция программы (Linux) |
| benchmark.slurm | SLURM-скрипт для бенчмарка |
| run_tests.slurm | SLURM-скрипт для верификации |
| data/ | Папка для входных/выходных файлов |
| results/ | Папка для результатов бенчмарка и графиков |

## Входные данные (матрицы)

### Формат входных файлов

Матрицы хранятся в текстовых файлах в папке data/:

- N — размер матрицы (первая строка)
- a_ij — элементы матрицы (разделены пробелами)

Создаются при помощи `scripts/gen_matrix.py` для выполнения тестов.

## Как запускать на суперкомпьютере

## 0. Загрузка модулей
module load intel/mpi4
module load intel/icc18
## 1. Компиляция
bash
./build.sh
## 2. Верификация корректности
bash
sbatch run_tests.slurm
## 3. Бенчмарк производительности
bash
sbatch benchmark.slurm
## 4. Построение графиков
bash
python3 scripts/plot_mpi.py

### Вывод
MPI-реализация демонстрирует отличную масштабируемость на суперкомпьютере:

Максимальное ускорение: 9.00× для матрицы 200×200 на 8 процессах

Для больших матриц (≥1000) ускорение стабилизируется на уровне 6.9–7.6× (86–95% от идеального)

Производительность в однопоточном режиме: ~0.20 GFLOPS

Производительность на 8 процессах: ~1.4–1.9 GFLOPS

Эффективность параллелизации: 86–100% для всех конфигураций

## Требования для запуска
Суперкомпьютер «Сергей Королёв» (или любой кластер с SLURM)

Модули: intel/mpi4, intel/icc18

Python 3 с библиотеками: numpy, matplotlib, pandas
