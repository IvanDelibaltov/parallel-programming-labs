# Лабораторная работа №1: Последовательное умножение матриц

## Описание программы
Программа на C++ для умножения двух квадратных матриц.

## Структура проекта

| Файл | Назначение |
|------|------------|
| `src/main.cpp` | Основной код программы (умножение матриц) |
| `scripts/gen_matrix.py` | Генерация случайных тестовых матриц |
| `scripts/verify.py` | Верификация через NumPy |
| `scripts/test_verification.bat` | Автоматические тесты корректности |
| `scripts/benchmark.bat` | Тестирование производительности |
| `build.bat` | Компиляция программы |
| `data/` | Папка для входных и выходных файлов |

## Сборка и запуск

### 1. Компиляция
build.bat

text

### 2. Запуск верификации (проверка правильности)
cd scripts
test_verification.bat

text

### 3. Запуск бенчмарка (измерение производительности)
benchmark.bat

text
